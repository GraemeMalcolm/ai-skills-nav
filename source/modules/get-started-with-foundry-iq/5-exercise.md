If you have an Azure subscription, you can use it to explore Foundry IQ in Microsoft Foundry for yourself.

In this exercise, you'll explore Microsoft Foundry IQ and connect an AI agent to a knowledge base. You'll examine how the agent retrieves enterprise information and uses citations to support its responses.

> **NOTE**: If you don't have an Azure subscription and want to explore Microsoft Foundry, you can [sign up for an Azure account](https://azure.microsoft.com/pricing/purchase-options/azure-account?cid=msft_learn). Review the exercise prerequisites and clean-up instructions to understand any services and costs involved.
