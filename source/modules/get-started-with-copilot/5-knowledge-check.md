::: knowledge-check type="quiz" show-answers="true" allow-retry="true"

- item:
  - question: You need to compare information across several files and organize a multi-step analysis. Where should you start?
    a: Use an agent such as Analyst
    b: Draft the result directly in Outlook
    c: Search for each exact file name manually
    answer: a
    feedback: Agents are designed to structure an approach, work across multiple sources, and manage complex or multi-step tasks.
- item:
  - question: What happens when you ask Copilot about a file that you do not have permission to access?
    a: Copilot requests temporary access on your behalf
    b: Copilot can summarize the file but cannot show its location
    c: Copilot cannot use or surface the file
    answer: c
    feedback: Copilot follows existing Microsoft 365 access controls and does not expand a user's access to restricted content.
- item:
  - question: Which four elements help make a Copilot prompt accurate and useful?
    a: Audience, application, permissions, and formatting
    b: Context, goal, source, and expectations
    c: Keywords, file names, labels, and citations
    answer: b
    feedback: Effective prompts describe the context and goal, identify the source, and set expectations for the response.

::: end-knowledge-check
