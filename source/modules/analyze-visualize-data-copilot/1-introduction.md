Imagine you're part of a growing retail business, tasked with preparing a quarterly sales report for leadership. You need to analyze sales data, identify trends, and create charts your manager can present to the team — but you're short on time and don't have advanced technical skills.

In this module, you'll use Copilot in Excel to analyze data, generate visual charts, and analyze text for themes and sentiments — all through natural language prompts. You'll then explore the Analyst agent, which takes your analysis further by reasoning across multiple files to surface deeper insights and produce shareable reports. Along the way, you'll learn when to reach for each tool so you can choose the right approach for any data task. The module wraps up with an exercise where you can apply these tools to a real dataset.

By the end of this module, you're able to:

- Use Copilot in Excel to analyze data and visualize trends using natural language.
- Access and use the Analyst agent to perform deep data analysis and generate actionable insights.
- Understand how Copilot in Excel, the Analyst agent, and Copilot Chat each serve different data analysis needs.
