In this module, you used Copilot in Excel to analyze data, generate charts, analyze text columns for themes and sentiments, and build formulas using natural language prompts. You also explored how the Analyst agent reasons across multiple files to surface deeper insights and produce shareable reports.

You learned when to use each tool—Copilot in Excel for in-spreadsheet analysis, the Analyst agent for complex multi-file tasks, and Copilot Chat for general questions and drafting—so you can choose the right approach for any data task.

You also completed an exercise where you used Copilot in Excel and the Analyst agent on a real dataset.

Now that you've completed this module, you're able to:

- Use Copilot in Excel to analyze data and visualize trends using natural language.
- Access and use the Analyst agent to perform deep data analysis and generate actionable insights.
- Understand how Copilot in Excel, the Analyst agent, and Copilot Chat each serve different data analysis needs.
