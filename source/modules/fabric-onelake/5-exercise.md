---
title: Exercise - Discover and connect to data in OneLake
description: >-
  Interactive exercise to practice discovering data through the OneLake catalog, creating shortcuts, querying with SQL,
  and exploring semantic models.
---

In this exercise, you create a lakehouse with sample data, discover it through the OneLake catalog, create shortcuts for cross-workspace access, query data using the SQL analytics endpoint, and explore semantic models.

> **NOTE**: You need access to a Microsoft Fabric-enabled workspace to complete this exercise. For more information, see [Getting started with Fabric](/fabric/get-started/fabric-trial) to enable a Fabric trial license.

This lab takes approximately **30** minutes to complete.
